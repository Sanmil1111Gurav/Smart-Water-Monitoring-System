About the System
SmartWater System
Smart Water Level Monitoring & Automation System

The system monitors water level using a water-level sensor connected to an ESP32 and automatically controls the water pump according to configured thresholds.

Water Level Sensor
ESP32

How the System Works
01

Step 1 — Water Level Monitoring

The water-level sensor measures the current water level.

02

Step 2 — ESP32 Processing

The ESP32 reads the sensor value and sends telemetry to the backend.

03

Step 3 — Dashboard Monitoring

The dashboard displays the latest actual water level, pump status, buzzer status, and device connection status.

04

Step 4 — Automatic Pump Control

When Auto mode is enabled, the configured thresholds determine when the pump starts and stops.

05

Step 5 — Safety Monitoring

If the emergency overflow threshold is reached, the system triggers the appropriate safety action and alarm.

06

Step 6 — Notifications

Important system events and emergency conditions can generate notifications and email alerts according to the user's notification preferences.

Configuration & Thresholds

The SmartWater system relies on three primary thresholds configured in Settings → Configuration:

Low Water Threshold

When the water level reaches or falls below this value, Auto mode can start the pump.

Full Water Threshold

When the water level reaches or exceeds this value, Auto mode stops the pump.

Emergency Overflow Threshold

When the water level reaches or exceeds this value, the system treats it as an emergency/overflow condition and performs the configured safety action.

Required Relationship
Low Threshold < Full Threshold ≤ Emergency Threshold
Valid threshold range: 0–100%
Settings → Configuration remains the only place where thresholds are changed.
Device Status Guide

Device statuses reflect real-time telemetry from connected hardware:

Connected

The device is communicating with the backend and recent telemetry/heartbeat has been received.

Not Connected

No valid recent communication has been received from the ESP32.

Not Available

The system does not currently have enough actual device information to report that component's status.

Important: Opening this page does not report a device as connected unless confirmed by actual backend heartbeat telemetry.

Troubleshooting
ESP32 Not Connected
  • Verify ESP32 power.
  • Verify Wi-Fi connection.
  • Check the backend is running.
  • Check the ESP32 is sending telemetry.
  • Check the device ID/configuration.
Water Level Not Updating
  • Verify sensor wiring.
  • Verify sensor power.
  • Check ESP32 sensor readings.
  • Check ESP32-to-backend communication.
Pump Not Starting
  • Verify Auto mode is enabled.
  • Check the configured Low Water Threshold.
  • Check L293D connections.
  • Check motor/pump power supply.
  • Check whether an emergency safety condition has stopped the pump.
Email Notification Not Received
  • Verify the registered email address.
  • Check Notification preferences.
  • Check spam/junk folder.
  • Verify backend email/SMTP configuration.
  • Check backend email-service errors.
